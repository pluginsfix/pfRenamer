# pfRenamer

Высокопроизводительный плагин для серверов Minecraft (Paper, Purpur, Folia), предназначенный для рекурсивного сканирования и массовой пакетной замены текста, доменных имен и ссылок во всех файлах конфигураций плагинов (`.yml`, `.yaml`, `.json`, `.txt`, `.toml`, `.properties`, `.conf`, `.cfg`, `.xml`, `.csv`).

## Возможности

- **Асинхронная обработка**: сканирование и перезапись сотен файлов производятся в фоновом пуле потоков без задержек и лагов основного тика сервера.
- **Поддержка любых символов и кодировок**: корректная обработка UTF-8, включая стилизованные Unicode-символы (small caps, спецсимволы).
- **Безопасность**: защита от повреждения бинарных файлов (`.jar`, `.db`, `.dat`), пропуск слишком больших файлов (>10MB) и автоматическое исключение служебных каталогов.
- **Режим проверки (dry-run)**: возможность оценить количество файлов и строк для замены перед фактической записью на диск.
- **Гибкая настройка**: добавление любых собственных правил замены, расширений и списков исключений в `config.yml`.

## Команды и права

| Команда | Описание | Право |
|---|---|---|
| `/pfrenamer run` | Запустить процесс поиска и замены во всех конфигурациях плагинов | `pfrenamer.admin` |
| `/pfrenamer check` | Выполнить предварительную проверку без изменения файлов | `pfrenamer.admin` |
| `/pfrenamer reload` | Перезагрузить файлы конфигурации и сообщений | `pfrenamer.admin` |
| `/pfrenamer help` | Показать список доступных команд | `pfrenamer.admin` |
